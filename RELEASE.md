# ItundaFace 2.0.0

ItundaFace 2.0.0 establishes the first complete visual-system foundation for Itunda.

## Scope

- Reactions
- Communication
- Places / maps / mobility
- Identity / security
- Commerce / marketplace
- Payments / finance
- Rwanda-native culture
- Motion/state grammar

## Usage guidance

Use flat glyphs for compact inline UI and 3D glyphs for deliberate prominent moments. Preserve semantic colors and use Itunda indigo selectively as the identity accent.

## Quality

Validate new glyphs at 14px and 24px for flat UI, and 32px, 40px, 48px, and 64px for 3D. Check optical balance, light/dark readability, silhouette continuity, and accessibility labels.
