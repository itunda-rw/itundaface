# ItundaFace Showcase — Localization & Theme Contract

The showcase treats localization and theme as product behavior, not decorative website features.

## Supported locales

- `en` — English
- `rw` — Kinyarwanda
- `fr` — French

The locale switcher must persist the selected locale and update the document language. The default locale is English.

## Localization scope

All user-facing copy should belong to the same locale contract:

- navigation and section headings
- hero copy and calls to action
- visual-system explanations
- 3D demo controls and hints
- phone simulator labels, actions, transactions, tabs and status text
- Agent Network labels, actions and explanatory steps
- gallery category filters and glyph names
- accessibility labels that are visible to assistive technology
- footer and metadata text

A language switch must never leave core simulator or demo controls in a different language while the surrounding page has changed.

## Translation rules

1. Keep product names such as **ItundaFace**, **Itunda**, **Agent Network**, and **IDS** unchanged unless an official localized product name exists.
2. Translate meaning, not English word order.
3. Keep financial amounts, dates, IDs and technical identifiers semantically stable across locales.
4. Prefer short UI labels suitable for mobile surfaces.
5. Kinyarwanda copy should be natural product language, not a literal English translation.
6. French copy should use concise product/UI conventions rather than formal prose.
7. Accessibility labels should describe the same semantic object in every locale.

## Theme contract

The showcase supports:

- light theme
- dark theme
- persisted theme selection
- semantic contrast for text, controls and surfaces
- `color-scheme` synchronization
- `prefers-reduced-motion` compatibility

Brand indigo remains the identity anchor:

- Light: `#7472F4`
- Dark: `#7675F8`

Semantic glyph colors remain semantic in both themes. Theme switching must not recolor an object merely to make the page look different.

## Quality gate

Before publishing a localization/theme change:

- switch through EN → RW → FR and inspect every visible interactive surface
- test light → dark → light while each locale is active
- verify no untranslated core UI remains
- verify hero typography retains intended emphasis in every locale
- verify glyph filters and names change with locale
- verify `aria-label`, `lang`, title and meta behavior remain coherent
- verify reduced-motion users do not depend on animation to understand the demo
- verify the page remains dependency-free and works on GitHub Pages

The showcase is a reference implementation of ItundaFace product language. New UI examples should follow this contract rather than introducing a separate localization or theme convention.
