# ItundaFace Showcase

Static, dependency-free product showcase for viewing ItundaFace in realistic UI contexts.

Open `showcase/index.html` locally or publish the repository with GitHub Pages.

The page includes:
- real-life mobile UI examples for finance, chat, and identity
- flat glyph gallery
- 3D showcase
- core visual-system measurements
- light and dark themes
- English, Kinyarwanda, and French localization
- interactive 3D expression and phone UI demos
- Agent Network examples

Artwork is loaded from the canonical SVG files in this repository.

## Localization and theme contract

See [`I18N.md`](./I18N.md) for the supported locale contract, theme behavior, accessibility expectations, and release QA checklist. Localization is intended to cover the complete visible product experience, including simulator controls and gallery labels—not only the marketing copy.
